# 미해결 이슈

원인을 아직 모르는 것, 재현이 불안정한 것을 여기 남긴다.
원인이 밝혀지고 조치가 끝나면 해당 사이트 레시피의 이력 표로 옮기고 여기서 지운다.

문서 규칙은 `.claude/rules/writing.md`.

## 양식

```markdown
## <한 줄 증상>

- 발견: 2026-08-21
- 대상: workflow <id> / 사이트 / 전체
- 재현: <되는지, 조건은 무엇인지>
- 확인한 것: <해봤고 아니었던 것들>
- 가설: <근거와 함께. 근거 없으면 가설이라고 명시>
```

확인 못 한 것을 사실처럼 쓰지 않는다. "아마 ~일 것" 은 가설 항목에만 쓴다.
