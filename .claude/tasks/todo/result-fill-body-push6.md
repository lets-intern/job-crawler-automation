`title`·`company`·`deadline`·`body`·`source_url` 빈 건이 전부 0 이다.

## 왜 비웠나

작업 파일이 쓰인 시점의 "216건 중 86건 본문 없음" 은 실행 시점에 이미 해소돼 있었다. 그 86건
(LG 83, 삼성 3)은 Push 4·5 를 진행하는 동안 지워졌고, 실행 직전 본문 빈 건은 0 이었다.

그래도 비운 이유는 데이터가 두 경로에서 섞여 있었기 때문이다. 현대 20건과 롯데 8건이 옛 셀렉터
경로로 들어온 것이고, `source_url` 이 같아 재수집으로는 덮이지 않는다. 확인한 결과 현대 20건은
`source_url` 이 이전과 전부 같은데 본문은 20건 모두 달라졌다 — 옛 경로가 붙이던
`조직소개`/`직무상세` 머리말이 사라지고 API 가 주는 평문으로 바뀌었다. 비우지 않았다면 이 20건은
옛 값 그대로 남았을 것이다.
