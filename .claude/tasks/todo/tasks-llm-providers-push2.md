## 알아 둘 것

**마이그레이션이 필요 없다.** 키는 `app_settings` 에 들어간다. `app/notify/settings.py` 가 같은
표를 쓰면서 전용 모듈만 따로 둔 선례를 그대로 따른다 — `app/settings.py` 는 `dict[str, int]` 를
내보내는 API 에 묶여 있어서 문자열 값을 얹으면 이미 있는 화면이 흔들린다.

**키가 스냅샷에 실리는 것은 결정된 사항이다** (2026-08-27). `VACUUM INTO` 가 DB 전체를 뜨므로
`app_settings` 에 넣으면 자동으로 실린다. **빼는 코드를 쓰지 않는다.** 대신 내보내기 화면에
파일에 키가 들어 있다는 것을 적는다.

**화면에 값을 다시 그리지 않는다.** 저장된 키는 있는지 없는지와 끝 네 자리만 보여준다.
저장 응답에도, 로그에도, 예외 메시지에도 전체 값이 없어야 한다.
