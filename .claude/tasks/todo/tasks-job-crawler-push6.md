- 운영자 한 명을 가정한다. 인증·세션·익명 트래픽 대응은 PRD 비목표다 (`.claude/rules/core.md`)

  화면이 읽기 어렵다는 판단이 나와 사용자가 Tailwind 도입으로 뒤집었다. `tasks-job-crawler-push9.md` 참조.
- **결정됨 (2026-08-22): CSS 를 만들지 않는다.** 스타일시트 파일도, `<style>` 블록도, 인라인
  `style` 속성도, 클래스 기반 디자인도 넣지 않는다. 시맨틱 HTML 과 브라우저 기본 렌더링,
  그리고 HTMX 속성만 쓴다.
  정적 파일 마운트도 만들지 않는다 — 서빙할 자산이 없다.
  구조가 필요하면 `table`, `form`, `fieldset`, `details`, 제목 레벨 같은 태그 자체로 만든다.
  HTMX 가 거는 클래스(`htmx-request` 등)는 동작에 필요하므로 예외다.
  이유: 운영자 한 명이 쓰는 내부 도구고, 파이프라인이 제품이다 (`.claude/rules/core.md`).
  화면 판정 기준은 보기 좋은지가 아니라 **부분 갱신이 실제로 도는지**다
