## 무엇이 끊겨 있나

2026-08-22 브라우저 QA 에서 확인했다. 화면으로 크롤러 등록 → 셀렉터 손 편집 → 테스트 실행까지
갔고 전 필드 3/3 성공이 나왔는데, **거기서 멈춘다.**

워크플로우 화면이 스스로 적고 있다.

> 등록된 워크플로우가 없다. 테스트를 통과한 크롤러를 워크플로우로 승격하면 여기에 나온다
> (지금은 `POST /api/workflows` 로만 승격된다)

승격이 API 로만 되므로 주기 실행·정규화·데이터 조회·검수까지 전부 도달할 수 없다.

PRD 3장 사용자 플로우 4~5번이 이 화면을 요구한다 — "워크플로우에 넣기 버튼 → 이름 입력 →
등록 → 주기 설정". `app/api/workflows.py` 에 승격 API 는 Push 4 에서 이미 만들어져 있고
화면만 없다. Playwright 때와 같은 종류의 누락이다.

## 관련 파일

- `app/templates/fragments/test_targets.html` - 테스트를 통과한 크롤러에 승격 수단
- `app/templates/pages/workflows.html`, `app/templates/fragments/workflow_*.html`
- `app/api/ui_workflows.py` 또는 그에 해당하는 화면 라우터
- `app/api/workflows.py` - 이미 있는 승격 API 를 재사용한다. 두 번째 경로를 만들지 않는다

## 선행 조건
