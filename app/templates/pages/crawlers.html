{# 등록은 셀렉터 생성(실측 5.6~10.5초)에 경로 판정이 붙어 있고, 렌더까지 가는 사이트는 그만큼 더 걸린다. 누른 뒤 아무 변화가 없으면 눌렸는지 알 수 없다 — 요청이 도는 동안 버튼을 잠그고, 버튼 옆과 결과 영역 두 곳에 무엇을 기다리는지 적는다 #}
목록 URL 하나만 넣는다. 나머지는 등록이 알아서 정한다

가져오는 방식을 고르지 않는다. 등록이 목록 페이지를 정적으로 먼저 받아 보고, 목록이 없으면 브라우저로 렌더한 뒤 상세로 가는 길까지 스스로 찾는다. 목록이 JSON API 로 오는 사이트는 그 주소를 다시 불러 확인한 뒤 API 로 저장한다. 정해진 경로와 무엇을 보고 그렇게 정했는지는 아래 결과에 나온다.




비워 두는 것이 기본이다. 상세로 가는 길은 등록이 찾는다. 찾지 못했다고 나오면 그때 공고 하나의 주소를 여기 넣어 다시 등록한다 — 그러면 그 페이지를 보고 상세 셀렉터까지 만든다.




공고에서 회사명을 뽑지 못한 건에만 쓰인다. 페이지에 회사명이 있는 사이트는 비워 둔다.
